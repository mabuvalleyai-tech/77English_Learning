# 77English_Learning：拍照單字卡

幫孩子背英文單字的網頁 App：把課本的單字頁拍下來，自動整理成單字卡；點英文就會唸出發音。

目前版本：**v1.0**（版本紀錄見 [CHANGELOG.md](CHANGELOG.md)）

## 怎麼用

1. 用手機或電腦打開 App 連結（Claude 上的 Artifact 頁面）。
2. 按「📷 拍照新增單字」，拍一頁課本單字表或從相簿選照片（可一次選多張）。
3. 按「開始辨識」，第一次會問你是否允許頁面使用 Claude，按允許。約 20–60 秒後會列出所有單字。
4. 對照課本檢查，有錯直接改，按「儲存」。
5. 開始練習：
   - 點英文單字：唸出發音（速度可在首頁調成慢／正常／快）。
   - 「翻面看答案」後選「記住了」或「還不熟」。
   - 可切換「看英文猜中文」／「看中文想英文」、隨機順序、只練還不熟的。
   - 「單字表」可以一次看整組單字，逐一點喇叭聽。

## 技術說明

- 單一檔案 `index.html`，不需要安裝。
- 照片辨識：透過 Claude Artifact 的 `sample` 能力，用使用者自己的 Claude 帳號辨識，**不需要 API 金鑰**。
- 發音：瀏覽器內建的 Web Speech API（iPhone、Android、電腦都支援）。
- 儲存：在 Claude 裡開啟時存到帳號雲端（換裝置也看得到）；其他地方開啟時存在瀏覽器本機。
- 直接用瀏覽器打開這個檔案（不是透過 Claude）時，拍照辨識不能用，但範例單字、手動建立和發音都可以用。
